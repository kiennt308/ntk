# NB08 - Transformer Architectures in Crossmodal Affective Computing
## Chủ đề Tiếng Việt: Kiến trúc Transformer Đa phương thức và Tương tác Chéo

- **Ánh xạ Chương Luận Án**: **Chương 2 & Chương 3 (So sánh Đối sánh Transformer & MulT / MISA)**
- **Trọng tâm Nghiên cứu**: Multimodal Transformers (MulT), Cross-attention encoders, spatio-temporal self-attention, and long-range dependencies in continuous affective dynamics.
- **Tổng số bài báo khoa học chỉ mục**: **18 bài** (Giai đoạn 2023–2026)
- **Số lượng file PDF toàn văn sẵn có**: **13 file PDF** (trong thư mục [`pdfs/`](pdfs/))

---

## 🎯 Các Câu Hỏi Nghiên Cứu Trọng Tâm
1. Kiến trúc Multimodal Transformer giải quyết độ trễ pha (phase shift) giữa các tín hiệu như thế nào?
2. Cơ chế Positional Encoding thích ứng với chuỗi thời gian sinh lý phi đều đặn.
3. So sánh độ phức tạp tính toán giữa Self-Attention và Cross-Attention trong dung hợp đa tín hiệu.
